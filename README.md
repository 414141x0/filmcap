# FilmCap

The pages for the FilmCap iPhone app, served by GitHub Pages:

- `index.html`: the app's page (screens in `img/`, photos by the developer)
- `privacy.html`: the privacy policy (App Store Connect's Privacy Policy URL)
- `support.html`: support (App Store Connect's Support URL)

Set in Allo (`fonts/`, SIL Open Font License 1.1, `fonts/Allo-OFL.txt`).
